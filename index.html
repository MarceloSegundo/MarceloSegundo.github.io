Projetos

Três projetos feitos sozinho, de ponta a ponta. Os dois primeiros têm código privado e aparecem como estudos de caso, com arquitetura e trade-offs.

01 · Java · IA aplicada

Assistente de vendas com IA para corretora de planos de saúde

Chat que qualifica o cliente e cota planos com preços vindos do banco via tool calling, para o modelo não inventar valor. Nasceu em Spring Boot e foi migrado para Quarkus com imagem nativa.

Quarkus · LangChain4j · Spring Boot 3 · Spring AI · PostgreSQL · GraalVM/Mandrel · React 19

02 · Go · PWA

ibmoria: comunicação da Igreja Batista Moriá

PWA feito para tirar os avisos da igreja dos grupos de WhatsApp: canais, notificações push, login por código no celular e uma auditoria de segurança com 5 achados corrigidos.

Go · chi · pgx · PostgreSQL · S3 · React · TypeScript · Web Push

03 · Java · em desenvolvimento · código aberto

agenda-salao-online

Agendamento online para salões em Spring Boot, multi-tenant, com as decisões de arquitetura registradas em ADRs. É o código que você pode ler agora.

Java 21 · Spring Boot 3 · Spring Security + JWT · Spring Data JPA · PostgreSQL · OpenAPI

Experiência

Edu3 · ERP escolar SaaS

Estágio (nov/2020) → Júnior (jan/2022) → Pleno (jul/2025 – atual)

Mais de 50 escolas e 4 prefeituras multi-campus, com unidades de mais de 4 mil alunos e mais de 200 acessos simultâneos. Equipe enxuta: levanto requisitos, participo das decisões de arquitetura com o sênior, implemento e reviso o código do time.

  • Pagamentos: integrações de cobrança com Banco do Brasil, Bradesco e Itaú via boleto e CNAB (remessa/retorno), gateways online (PjBank, Educbank, Safe2Pay), cartão e PIX, além de conciliação bancária e relatórios financeiros.
  • Fiscal: emissão de NF-e e NFS-e via Migrate/Invoicy. Conduzi a adaptação de todo o sistema ao novo modelo da nota fiscal nacional e à Reforma Tributária (IBS e CBS).
  • Engenharia: lidero a implantação de testes unitários (JUnit, Mockito) na camada de serviços, mentorei dois estagiários e contribuo com Docker, Kubernetes e o CI/CD (GitLab + Drone).

Java · Hibernate/JPA · MariaDB · Docker · Kubernetes · GitLab CI · Drone
